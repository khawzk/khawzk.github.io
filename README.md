# khawzk.github.io

Personal site for Mark Khaw (Khaw Zhe Kang), GenAI and cloud solution architect. Served by GitHub Pages at https://khawzk.github.io/.

- `index.html` is the whole site: one static page with inline CSS and JS, no build step.
- `cv.pdf` is the resume linked from the "Download CV" button. Replace the file to update it.
- The carousel's skill-radar slide reads `/SGJobRadar/data/latest.json` (published by the [SGJobRadar](https://github.com/khawzk/SGJobRadar) repo's Pages site). If that file can't be loaded, the slide shows the snapshot built into `index.html`.
